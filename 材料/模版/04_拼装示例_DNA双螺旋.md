## 二、课标与知识结构化分析

### 1. 课标要求
概述 DNA 分子由四种脱氧核苷酸构成，通常由两条链反向平行盘旋成双螺旋结构；认识模型建构是科学研究的重要方法。

### 2. 大概念与知识点网络

| 层级 | 内容 |
|---|---|
| 大概念 | 结构决定功能 |
| 核心知识点 | DNA 基本单位、单链连接、双链反向平行、碱基互补配对 |
| 前驱知识 | 核苷酸、磷酸、脱氧核糖、碱基 |
| 后继知识 | DNA 复制、基因表达 |
| 相似概念 | RNA 单链结构、蛋白质多肽链 |
| 情境关联 | 遗传信息储存、亲子鉴定、刑侦 |

### 3. 教材地位
本节是必修2的核心，前承"减数分裂与受精作用"对遗传物质传递的需要，后开启 DNA 复制与基因的表达，是"结构决定功能"大概念的经典载体。

### 4. 核心素养指向
- **科学思维**：用证据推理判断、在建模中演绎归纳。
- **科学探究**：体验科学家模型建构—检验—修正的探究历程。
- **社会责任**：认同模型对生命现象的解释力（亲子鉴定、刑侦应用）。

## 六、核心问题与问题链

**核心问题：** DNA 作为遗传物质，其分子结构是怎样的？该结构如何实现遗传信息的储存功能？

**问题链：**
1. 【事实性】DNA 的基本单位是什么？由哪些部分组成？
2. 【解释性】DNA 要储存、保持、传递遗传信息，结构上必须满足哪些要求？
3. 【推论性】根据 X 射线衍射和碱基含量数据，能推出 DNA 可能是什么结构？
4. 【模型性】如何用模型表示 DNA 的双链与碱基配对关系？
5. 【反思性】我们如何知道"双螺旋 + 碱基互补配对"这个结论是可靠的？

## 八、板书 / 认知地图设计

```text
DNA双螺旋结构模型

一、功能需求：储存、保持、传递、表达遗传信息
二、建楼与检验
   1. 可行模型：单链/双链/三链；磷酸内/外
   2. 证据检验：X射线→螺旋；碱基A≈T,G≈C；磷酸带负电→外
   3. 定稿：双链反向平行、碱基互补配对
三、结构要点
   1. 基本单位：脱氧核苷酸
   2. 连接方式：磷酸-脱氧核糖-碱基
   3. 碱基配对：A=T, G≡C

副板书：
【学生易错】配对写反、磷酸在内侧、未考虑方向性
```
