# 高中生物模块化教案模板系统 · 使用说明

> 一套**可拼装**的高中生物教案模板，帮助新手教师/师范生快速生成结构完整、坡度合适的教学设计。

## 模板系统构成

**`主模板` + `课型插件` + `原子化素材卡` = 一份完整教案**

| 组件 | 文件 | 说明 |
|---|---|---|
| 通用主模板 | `01_通用主模板.md` | 所有课型必选，含课标/知识结构化/ZPD/目标/活动/板书/作业/反思十大板块 |
| 课型插件 | `课型插件/` | 按内容选择，可单选或组合 |
| 原子化素材库 | `原子化素材库/` | 可插入任意模板的可复用素材卡 |
| 拼装示例 | `03_拼装示例_DNA双螺旋.md` | 一个可参考的完整拼装样例 |

## 使用流程（五步法）

1. **先做知识结构化**：画出「大概念 → 知识点 → 前驱后继 → 相似 → 情境」网络，先读懂知识再讲课。
2. **再判 ZPD**：用前测、提问或作业，确定班级的「现有发展区 / 潜在发展区 / 未来发展区」。**教学支架应主要放在潜在发展区（ZPD）**。
3. **选择课型插件**：概念模型课、科学史课、验证实验、探究实验可单选或多选（如 DNA 双螺旋 = 概念模型 + 科学史）。复习课用简版插件 E。
4. **插入原子卡**：按活动需要，从素材库挑功能分析、模型列举、证据整合、变量表、互评量表等直接贴入。
5. **保持教—学—评一致**：每个目标至少对应一个评价任务，每个活动都有检验点。

## 设计要诀

- **课型选择对照**：见 `02_课型插件_总览.md` 中的「内容 × 插件」对照表。
- **优先学生认知逻辑**：短期教学可先按学生认知逻辑组织，长期单元再兼顾学科逻辑。
- **预设与生成并重**：预设任务链，但资料和提示可在学生最需要的时刻再提供。
- **坡度设计**：过渡性知识（教学支架）的坡度，应由 ZPD 诊断决定——太难击穿最近发展区，太易落回现有发展区。

## 文件格式说明

- 所有文件均为 UTF-8 编码的 Markdown。
- 模板中的 `____` 或【注释】为待填写占位。
- 「推荐原子卡」指素材库中对应编号的原子卡，可直接插入对应环节。
