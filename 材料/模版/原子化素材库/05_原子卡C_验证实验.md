---

## 原子卡 C1：原理复述卡

```markdown
【任务】用自己的话复述本实验的原理。
【支架】要点提示：
- 该原理基于什么生物学知识？
- 实验中的试剂/方法如何体现这一原理？
【评价】能否正确、完整复述，并与已知知识建立联系。
```

## 原子卡 C6：实验结论句式

```markdown
【结论句式】
在本实验中，通过____（操作），我们观察到____（现象），这说明____（结论）。
因此该结论____（支持/不支持）已知原理，原因为____。

【评价】结论是否严格基于证据，不超出数据下结论。
```
