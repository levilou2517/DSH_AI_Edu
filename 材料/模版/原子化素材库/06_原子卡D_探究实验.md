## 原子卡 D1：可探究问题筛选卡

**【用途】** 从生活情境中筛选"可探究"的科学问题。

| 标准 | 你的问题是否符合 |
|---|---|
| 可通过实验检验？ | 是 / 否 |
| 变量可操作、可测量？ | 是 / 否 |
| 有明确的假设方向？ | 是 / 否 |
| 在可接受的时间/材料范围内可行？ | 是 / 否 |

> 须满足全部"是"，才可作为正式探究问题。

## 原子卡 D2：假设句式卡

```markdown
如果 ____，那么 ____，因为 ____。
```

> **示例**：如果温度影响酶活性，那么在最适温度下酶活性最高，因为温度过高或过低都会影响酶的空间结构。

## 原子卡 D7：结论与反思句式

```markdown
【结论句式】

【反思句式】

下次改进：____。
```
