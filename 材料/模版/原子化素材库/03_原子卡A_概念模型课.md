# 原子卡库 · 03 原子卡 A（概念模型课）

> 用于 **插件 A：概念模型建构课** 的各环节。可从任意卡直接摘取插入主模板"学习活动序列"。

---

## 原子卡 A1：功能需求分析

```markdown
【任务】某物质要作为遗传物质，必须满足哪些功能？
【支架】功能清单：储存遗传信息、保持遗传信息、传递遗传信息、表达遗传信息、结构稳定、可复制。
【学生活动】小组讨论，列出 3—5 条，并说明对应的结构要求。
【评价】能否将功能要求与结构特点联系起来。
```

---

## 原子卡 A2：可能模型列举

```markdown
【任务】用绘图或列表方式，列出 DNA 分子所有可能的模型。
【支架】组合表：
- 链数：1 链 / 2 链 / 3 链
- 磷酸位置：内侧 / 外侧
- 碱基位置：内侧 / 外侧
- 连接方式：磷酸-脱氧核糖-碱基
【学生活动】分组列举，全班汇总。
【评价】模型是否多样、是否符合化学连接规则。
```

---

## 原子卡 A3：模型检验与修正

```markdown
【任务】根据证据，判断哪些模型不合适，并修正。
【证据卡】
- 证据 1：X 射线衍射图谱显示 DNA 是螺旋结构。
- 证据 2：碱基含量 A≈T，G≈C。
- 证据 3：磷酸基团带负电，位于内侧不稳定。
【学生活动】逐条检验，排除或修正模型。
【评价】能否用证据支持判断。
```

## 原子卡 A5：模型定稿与互评

```markdown
【任务】绘制最终模型并讲解。
【支架】检验清单：
- 是否满足所有功能需求？
- 是否符合所有证据？
- 能否清楚讲解各部分作用？
【学生活动】绘制定格 → 小组讲解 → 同伴互评。
【评价】模型是否完整满足所有检验条件。
```

## 原子卡 A6：解释预测任务

```markdown
【任务】用已定稿的模型解释功能、预测变化。
【示例问题】
- 为什么 DNA 能精确复制遗传信息？
- 若某碱基对替换，可能产生什么后果？
- 若将 DNA 置于高温环境长时间加热，结构会怎样变化？依据是什么？
【评价】能否用模型进行迁移解释与预测。
```
