# 原子卡库 · 02 核心问题与问题链模板

> **用途**：设计指向大概念的核心问题及其层层递进的问题链。
> 对应主模板第六节"核心问题与问题链"，以及插件 A/B 的"核心问题"。

## 核心问题模板

> 核心问题：____ 如何解释 ____？

## 问题链模板

```markdown
核心问题：____ 如何解释 ____？

问题链：
1. 事实层：____ 是什么？
2. 解释层：为什么 ____？
3. 证据层：有哪些证据支持 ____？
4. 模型层：如何用模型表示 ____？
5. 迁移层：如果 ____ 改变，会怎样？
6. 反思层：我们如何知道这个结论是可靠的？
```

## 使用提示

- **问题坡度**：低层（事实/解释）让学生"够得着"，高层（迁移/反思）挑战学生思维，体现 ZPD 坡度。
- **一条链贯穿**：整节课的提问都应指向并回扣核心问题，保持教—学—评一致。
