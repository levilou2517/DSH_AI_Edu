# 证据分级与"够不够"的判断

> 依据：T-BUILTIN-009 / 010 / 012 / 015
> 用途：判定一份教学判断/评价是否有足够证据支撑。
> 服务：class-eval（模式 A / 模式 B）、class-profile、teacher-growth、quiz（归因）、lesson-plan（学情分析部分）。
> 引用约定同 `digests/README.md`：`〔T-BUILTIN-nnn p.N〕`，页码对应原 PDF 的 `<!-- p.N -->`；引证 ≤40 字；标 `〔推断〕` 者为项目内的合理延伸，不得冒充文献结论。

---

## 一、数据 ≠ 证据

### 1.1 文献给的链条

这几篇文献都把"从数据到证据"当作一个**要付出加工的转化过程**，而不是采集完就自动成立：

- 循证教学要求"数据化与有效性"两者兼备，数据只是原料〔T-BUILTIN-009 p.2〕；证据的获取若"片段性"、分析若"表层性"，就撑不起决策〔T-BUILTIN-009 p.2〕。
- 技术侧把杂乱的原始数据"经自动清洗、标注与分类"转成"标准化的证据单元"，这一步是证据生产〔T-BUILTIN-009 p.2〕。
- 循证教研的知识生产遵循"数据→信息→知识→智慧"的递进逻辑〔T-BUILTIN-010 p.3〕；系统不能止于呈现基础数据，否则教师陷入"数据丰裕而洞见匮乏"〔T-BUILTIN-010 p.3〕。
- 原始数据必须"转化为具有明确教学意义的'学情证据'"〔T-BUILTIN-015 p.2〕；分析要"精准定位问题的根源，而非仅关注表面错误"〔T-BUILTIN-015 p.2〕。

反例（取自 `skills/class-eval.md` 的示例 payload）：某课堂转写里"连续讲述未插入提问"是**数据**；"支架二级没有落地"才是**证据支撑下的判断**——中间要经过：这段讲授对应哪一个设计环节、学生这 6 分钟在做什么、有没有别的解释（如学生正在动手）。把过程数据与教学环节对齐，是"教学评价调整"闭环成立的前提〔T-BUILTIN-009 p.3〕〔推断〕。

### 1.2 转化的四层与各层条件

| 层 | 是什么 | 进入下一层的条件（缺一不可） |
|---|---|---|
| ① 原始数据 | 转写文本、随堂测答卷、作品照片、操作日志、教师回忆 | **可定位**：有来源文件/行号/题号；**未被改写**：证据只追加不改写 |
| ② 可观察事实 | 一句可核对的话，如"L142 学生问：为什么一定要 5′ 到 3′" | **可核验**：任何人回到原文都能找到同一句；**不含解释性形容词**（"学生很困惑"不是事实） |
| ③ 推断 | "该生对方向性存在概念混淆" | **与判断有推理关系**：写明"从事实 X 推断 Y，依据是 Z"；**可反驳**：写出"若 Y 不成立，会观察到什么" |
| ④ 结论 | 写入产物的判断，如"支架二命中率偏低" | **跨过门槛**：符合第二节的等级与第三节的四问；**标注等级与边界**；**D 级已剔除** |

三条通用铁律：

1. **可追溯**——每条结论能回到②层或①层的具体位置。教师若要求"直接给结论"，结论仍须带来源（哪份文件第几段 / 哪句自述），并写明"这是基于 N 条证据的推断，不是事实"。
2. **可反驳**——结论必须能写出"如果错了会看到什么"〔T-BUILTIN-009 p.4 "持续反思并更新证据" 的前提是证据可被新证据推翻〔推断〕〕。
3. **情境化**——"证据动态化应用的前提是证据的情境化"〔T-BUILTIN-009 p.4〕。同一条证据换班级、换课型不自动成立。

## 二、证据等级（本项目采用）

分级依据：数据源的性质（出自学生本人 / 出自现场观察 / 出自教师回忆 / 无来源）〔推断〕；并遵守三条上位约束——指标只呈现特征、不评价优劣〔T-BUILTIN-010 p.4〕；原始数据须转化为学情证据、且要能定位根源〔T-BUILTIN-015 p.2〕；证据须与情境匹配〔T-BUILTIN-009 p.4〕。

| 等级 | 什么算 | 能支撑什么结论 | 不能支撑什么 |
|---|---|---|---|
| **A 直接** | 学生独立作答、可核验的作品与测验结果（随堂测答卷、错题、操作轨迹、作品、后置测试成绩） | 掌握率与正确率（须带分子分母）、典型错误与错因归类、某支架/干预前后的变化对照 | 现场怎样被组织的（支架是否落地）、学生的真实意图、单次结果的长期趋势 |
| **B 间接** | 课堂话语片段、师生互动记录、教师观察记录、同伴听课笔记、录像 | 教学行为模式（讲授时长、提问后是否回收、学生话语占比）、环节执行与设计的偏差、教师的表达方式 | "学生已达成 / 未达成"的定论——行为指标测的是**参与与表现**，不等于**学会**〔T-BUILTIN-010 p.4，抬头率、举手频次等属"体现参与度的指标"〕 |
| **C 自述** | 教师回忆、教师自评、同伴印象 | 教师的困惑、意图、犹豫点、可练点；与 B 级并排呈现的"教师视角" | 学生的任何状态（达成、情绪、理解程度）——自述不含学生证据 |
| **D 推测** | Agent 从风格、语气、习惯推出来的东西；无来源的"一般情况"；由 A/B 证据外推至未覆盖情境 | **什么都不能支撑** | 全部 |

配套规则：

- **D 级不得进入产物结论。** 它可以出现在 `controversy`（作为待教师确认的假设）或对话里的提问中，且必须标为"待确认的假设"；不得写进 `overall_diagnosis`、`student_layers`、`growth_trend`、`preferences[].rule` 等结论位。
- **A 级不等于"足够"。** A 级只能支撑"这些学生在这批题上的表现"；要把结论外推到整节课、整个单元，还需 B 级把题目与教学环节对齐〔推断〕。
- **B 级不得单独转化为达成度结论。** 抬头率、举手率等指标"旨在客观呈现课堂教学特征，不评价教学优劣"〔T-BUILTIN-010 p.4〕；据此写"学生已掌握"即为越级。
- **C 级只能进 `teacher_view`。** 与 `model_view` 并列，二者差异写入 `divergence`，不能合并成一条结论。
- **等级前置测试的诊断价值要标注样本与情境。** T-BUILTIN-012 的诊断基于"区域内某重点中学高三共 126 名"学生〔T-BUILTIN-012 p.2〕，其结论在本班是否成立取决于班级水平与教学进度是否可比〔推断〕。

> 与 `contracts/constants.json` 的关系：本系统现有的 `evidence_levels`（`rct | quasi | small-n | review | opinion | unknown`）度量的是**"一条依据的证明强度"**（研究设计），本节 A–D 度量的是**"一条学生证据的直接程度"**（数据源）。两者不互相替代：给教案找理论依据用前者，给评价判学生达成用后者。同一产物中二者分别落在 `cites_theory[]` 与 `evidence[]` / `meta.evidence_note` 里，不得混写。

## 三、"证据够不够"的四问

任何结论落盘前，Agent 自问四句；有一问答不上，结论就降级或标 `insufficient_evidence`。

### 问 1：这条判断依据的是哪一级证据？

- 检查什么：结论位里每条断言是否挂着 A / B / C 标签与来源定位。
- 怎么算过：`student_layers`、`overall_diagnosis`、`growth_trend` 每一条都至少有一条 A 或 B 级引用；只有 C 级的判断只能出现在 `teacher_view`。
- 不过时：改写成"目前只有教师自述，无法判断"。

### 问 2：有没有相反证据？

- 检查什么：是否找过与结论相反的材料（答对的学生、做得好的环节、另一次表现相反的评价）。
- 怎么算过：产物里出现"已检查相反证据"的位置或摘要；`divergence` 不得为空占位。
- 依据：项目侧，`divergence` 必须存在，三条线一致才可写 `aligned`（见 `skills/class-eval.md`）；文献侧同理——"持续反思并更新证据"〔T-BUILTIN-009 p.4〕，新证据可以推翻旧证据。

### 问 3：样本/情境边界在哪？

- 检查什么：写没写清**几个班、多少人、什么水平校、哪一课时、题目覆盖哪几个观测点**。
- 怎么算过：`sample` 带 `n` 与有效份数；`limitation` 写清观测点范围（如"只覆盖 Q3/Q5 两个观测点，不代表整节课"）。
- 反例与依据：T-BUILTIN-012 的诊断限定在一校一批学生〔T-BUILTIN-012 p.2〕；T-BUILTIN-015 给出了"35% 未勾选平均分""62% 颠倒分子分母"这类带百分比的数据〔T-BUILTIN-015 p.2〕——**百分比必须带分母**，否则只是印象。
- 次数门槛（项目约定，已在 class-profile 落地）：同一支架类型 < 3 次会话不谈趋势；跨次趋势另需 ≥ 2 次可比证据（teacher-growth）。

### 问 4：如果结论错了，会看到什么？

- 检查什么：每条归因结论后面有没有一句"反驳条件"。
- 怎么算过：写出可观察的反例形态。例："若结论'支架二未落地'有误，则应在后续同类题上看到正确率快速回升；若后测正确率仍停在 45% 左右，说明卡点在概念本身而非支架"〔推断，参照 T-BUILTIN-012 p.6 的前后对照做法〕。
- 写不出反驳条件的结论，视为 D 级。

### 四问判定速查

| 四问结果 | 产物动作 |
|---|---|
| 4 问全过 | 可写入结论位，标注等级与边界 |
| 问 1 或问 3 不过 | 结论保留但降级描述（"仅对这 N 份作答成立"），并在 `degrade[]` 记录 |
| 问 2 或问 4 不过 | 不进结论位，转 `controversy` 交教师判断 |
| 缺 A/B 级证据 | `insufficient_evidence`，写出缺什么 |

## 四、微格/无学生场景的铁律

**无学生证据时只做内省，禁止推断学生达成度。**

这条规则的依据是双重的：

- 文献侧：指标只呈现特征、不评价优劣，须由教师自主评估〔T-BUILTIN-010 p.4〕；证据的"效度"仍"取决于与具体学情的匹配程度"〔T-BUILTIN-009 p.5〕——没有学情，就没有可匹配的对象。
- 项目侧：微格能检验的是教师的教学基本功与表达（导入、讲解、提问、演示、板书、结束等技能训练）〔T-BUILTIN-032 2.2.2〕，而不是学生学到了什么〔推断〕。

### 4.1 判定语句（写在产物 `meta.evidence_note`）

> 本次评价仅有〔微格录像 / 同伴观察 / 教师自述〕，**无学生作答、无随堂测、无师生话语记录**，故本报告：①只输出教师表达模式、提问与环节组织、可练点；②不输出学生达成度、掌握率、学生分层；③所有关于学生的描述均为**待验证假设**，请教师在真实课堂中核对。

### 4.2 允许 / 禁止的表述对照

| 禁止写 | 改成 |
|---|---|
| "学生基本掌握了平均分的含义" | "（假设）若真实课堂出现『先画等分线再写分数』的行为，可支持该目标达成；本次无证据" |
| "本节课达成度约 80%" | "本次无学生证据，不给达成度；建议用 3 道随堂题建立首个观测点" |
| "提问效果不好，学生反应冷淡" | "模式 B 中教师自述『提问后停顿较长、担心冷场』；这是教师感受，不是学生反应" |
| "板书可能让学生困惑" | "板书二级结构出现两次改笔；可练点：书写前先定层级（教师可自查）" |

### 4.3 模板（可直接套用）

```
【性质】微格内省（无学生证据）
【能做】教师表达模式 __ 条；环节组织与预设的偏差 __ 处；可练点 1 个：____
【不能做】学生达成度、掌握率、学生分层、学生学习困难归因
【下一步取证】建议随堂测 Q__（覆盖 __ 考点）；建议课中记 __ 处学生原话
【教师确认】以上可练点是否为你想练的方向？如否，请指出哪一处判断不符合现场。
```

### 4.4 与模式 A 的边界

一旦出现任何学生证据（哪怕只有 3 份作答），即转入模式 A，但仍按第三节四问标注样本边界；不得因"有了证据"就把 3 份样本的结论外推到全班〔推断〕。

## 五、提问模板（用于向教师索取证据）

索取证据时**先问有无、再问形态、最后问边界**。每条都要带"为什么问"。

1. **这次复盘手上有什么？** 是课堂转写/录像、听课笔记、学生作答，还是只有你自己的回忆？→ 决定走模式 A 还是模式 B。
2. **这次随堂测是全班都做了，还是只有部分学生？** 做了的那部分是多少人、交上来多少份？→ 决定分母，没分母的正确率不能写。
3. **能提供几份学生的原始作答（含错的）？** 不需要全部，3–5 份典型即可。→ A 级证据的入口。
4. **学生错的那几道，你判断卡在哪一步？** 请说现象，不说评价（哪一步算错、哪句话答偏）。→ 区分推断与事实。
5. **课堂里有没有哪一刻学生的话让你意外？** 尽量复述原话。→ 最可能的 B 级证据。
6. **这次课和上次同类课有什么不同？** 换了环节、换了题、还是换了班？→ 判断能否做前后对照。
7. **这套结论你想用到哪些班、哪些学生身上？** 是否跨班、跨层次？→ 界定外推边界。
8. **有没有与你的判断相反的情况？** 比如某几个学生这次反而做对了。→ 找相反证据。
9. **如果把这条判断写进档案，你担心哪里被误读？** → 预埋反驳条件与免责表述。
10. **这份证据里有没有不便记录的（学生姓名、家庭信息）？** 请说明能否脱敏。→ 合规与数据归属。
11. **这次听的是哪个班、什么水平的班？** 学生近期的学习进度和这次的内容对得上吗？→ 情境匹配度。
12. **下次能不能在 __ 环节加一道检测？** 只加一题也行。→ 把 C/B 级证据升级为 A 级的最小动作。

提问红线：一次最多 3 题；每题的"为什么问"必须由 Agent 自己写出，不能把决策负担原样丢回教师。

## 六、边界与不确定

1. **文献样本有限。** T-BUILTIN-012 是一校一批学生的一次诊断〔T-BUILTIN-012 p.2〕；T-BUILTIN-015 是单课例实践〔T-BUILTIN-015 p.1〕。它们示范的是**做法**，不是可推广的效应量，不得作为"某策略普遍有效"的依据。
2. **能力感指标有解释限度。** 抬头率、举手率、积极/消极词汇等由算法识别，接口理由是"辅助教师自主评估教学有效性"〔T-BUILTIN-010 p.4〕；不同系统的识别口径不一致，跨系统比较不成立。
3. **教师对系统可信度的要求。** 教师明确要求"清晰标注每个观测指标的推导逻辑"〔T-BUILTIN-010 p.8〕；因此本框架的 A–D 标注是**接口义务**，不是可选装饰。
4. **数据归属。** 教师要求"数据归属权和使用权应由教师主导"〔T-BUILTIN-010 p.8〕；本框架不得要求教师为凑证据而交出非必要数据。
5. **A–D 分级是本项目约定，不是文献原文的分级。** 文献提到的是 ESSA 对证据质量的严格分级〔T-BUILTIN-009 p.2〕与循证医学 5A 流程〔T-BUILTIN-009 p.4〕，均针对**研究证据**，不能直接照搬成课堂证据等级〔推断〕。若教师补充文献给出另一套分级，以教师补充为准，并在产物中记录冲突。
6. **"够不够"是相对判断。** 同一批证据对"这节课怎么样"可能不够，对"下次这个环节加一题"已经够。答"够不够"前先问清**这次要用来做什么决定**。
7. **不确定时怎么写。** 一律 `insufficient_evidence` + 缺什么 + 最小补证动作（见 4.3 模板"下一步取证"），不得用"待教师确认"代替真正的缺口说明。
