# 提炼框架（digests）

这不是论文摘要，是**从文献中提炼出的、Agent 真正要读的判断依据**。

## 好框架的四条标准

| 标准 | 判据 | 反例 |
|---|---|---|
| **完整** | 覆盖该类工作的全部关键决策点，不漏 | 只讲"要有学情分析"，不讲怎么判断学情够不够 |
| **具体** | 每个概念都落到"检查什么 / 问什么 / 怎么算过" | "支架要适度"——不可执行 |
| **可追溯** | 每条论断带 `T-BUILTIN-nnn p.N`，可自行核对 | 只写"研究表明…" |
| **可发挥** | 给原则与判据，不给固定模板；教师能在此基础上变通 | 写死一套流程，换课题就失效 |

## 引用约定

```
〔T-BUILTIN-029 p.7〕       内置文献第 7 页
〔T-DERIVED-002 p.3〕       教师补充文献第 3 页
```

- 页码与文献内 `<!-- p.N -->` 一致（原 PDF 页序）。
- 引证原文 **≤40 字**，超出即视为抄录，不允许。
- 标 `〔推断〕` 的段落是项目内的合理延伸，**不是文献结论**，不得冒充依据。

## 维护

框架随包更新。教师的补充文献放在 `$SHIBAN_ROOT/theory/derived/`，升级不覆盖。
若框架与教师补充文献冲突，**以教师补充为准**并记录理由——教师保有最终解释权。
