### 5.2 **关键发现：技能契约 vs 真实产物已「漂移」**

将现有技能（`.dsh/skills/*.md`）与 tar 包内真实闭环产物逐一对比：

| 技能 | 现有契约（skill 文件） | 真实产物（examples/*.json） | 漂移 |
|---|---|---|---|
| lesson-plan | 输出「2-3 个候选 JSON，各含 plan_id/cognitive_analysis/recommendation_reason/scaffold_suggestion」 | `lesson_plan_candidates.json`：每方案含 id/name/core_idea/objectives(三维)/key_points/difficult_points/scaffolds(5个富字段)/teaching_flow/anticipated_risks/applicable_scenarios，且方案 B 有 `refinement_40min` | **大漂移**：技能是「简化字段版」，产物是「完整教案版」。技能未反映真实产出深度 |
| quiz | 输出「3-5 题 JSON，含 stem/cognitive_level/answer」 | `current_quiz.json`：**7 题**（单选/填空/简答混合），每题含 options/score/scaffold/scaffold_label/attribution 多维归因，外加完整 grading_template 与 revision_log | **大漂移**：技能是「3-5 题简版」，产物是「归因型多维随堂测」 |
| class-eval | 输出「一致性判断/归因诊断/反思追问」三段 | `last_eval.json`：长篇循证评价（6 张画像表、学生分层 L1-L4、三周过渡设计、复测设计） | **大漂移**：技能契约远小于真实产物 |
| class-profile | 输出 8 字段 JSON + 写 `class_profile` 单表 | 真实建了 **6 张表**（class_lessons/scaffold_effectiveness/student_layers/students/quiz_results/q7_scoring） | **大漂移**：技能契约是单表，真实是多表画像 |

**含义**：四技能的现有 `.md` 定义已**落后于实践**。真实闭环是靠「子 Agent 被委派时的完整 prompt + 内联技能」跑出的（见 §6.2），现有 skill 文件若直接发给新子 Agent，会产出比预期简化的结果。**技能定义需按真实产物 schema 重写对齐**——这是 R2.6 / R4 / R3 能否稳定落地的前提。
