# v0.4.3 素材闭环用户验收说明

## 范围与状态

本轮交付素材库/编排引擎、CLI/工具源码、技能契约和隔离示例。正式素材位于独立 SHIBAN_ROOT，不进入师伴本体或发布包。没有安装当前 GUI、没有同步 lab、没有修改 VERSION 或发布标签。用户验收不由基础测试替代。

## 生成隔离示例

在 ShiBan 工作区执行：

```bash
python3 DSH_AI_Edu/scripts/demo_materials.py --root "$PWD/demo-v043-acceptance"
```

该脚本必须显式指定以 demo-/test-/tmp- 开头的目录名，并拒绝用户级默认 ~/.shiban。建议使用全新空目录，禁止使用真实教师库。输出 asset id、规格和文件路径；生成的素材是合成验收数据，不是正式库种子。

生成三份页面：

- data/assets/demo-cycle-page/main.html：细胞周期阶段动画与时间表。
- data/assets/demo-base-page/main.html：A-T 配对图形与嘌呤双环骨架示意。
- data/assets/demo-nested-page/main.html：已有编排页再成为子组件。

直接用浏览器打开文件，不需要新服务器或 GUI 预览。

## 浏览器验收

1. 动画与时间表都显示，改变同一原子的输入时各实例各自运行，样式和 DOM id 不互相污染。
2. 嵌套页正常显示；**仅对不含外部引用的原子**，把 `main.html` 单独移走并断网后仍可打开。
3. 手机窄屏不横向溢出，长标题不遮挡组件；各组件可独立滚动或适应高度。
4. 标题与标签含 <、>、引号时呈现文本，不改变页面结构；数据含 </script> 时不执行额外脚本。
5. 组件不能直接访问父页 DOM；这不意味着任意不受信任 HTML 已经过完整安全审计，正式素材仍须审查来源。
6. **依赖 vendor 的原子（重点、未验证）**：把素材根中 `碱基结构式` 编排进一个页面并打开。
   该原子以 `<script src="../vendor/smiles-drawer@2.4.1/smiles-drawer.min.js">` 相对引用外部库。
   沙箱 iframe 为不透明源（无 `allow-same-origin`），**其能否加载该 `file://` 子资源未经本机验证**（无可用浏览器）。
   若结构式不渲染，即为此限制；此时必须连同 `data/assets/vendor/` 保留目录结构，且"单文件搬移"不成立。


## 库与复用验收

使用同一个隔离根执行：

```bash
export SHIBAN_ROOT="$PWD/demo-v043-acceptance"
bash DSH_AI_Edu/bin/shiban-store asset suggest --kp 细胞 --kind html
bash DSH_AI_Edu/bin/shiban-store asset get --id demo-cycle-page
bash DSH_AI_Edu/bin/shiban-store asset compose --spec-schema
bash DSH_AI_Edu/bin/shiban-store asset reuse --id demo-cycle-page
```

确认查询不改变计数，显式 reuse 增一次；重复登记相同内容返回已有 id；重复提交相同编排不重复计数；缺必填、错类型/枚举、未知原子或已占用 id 的不同内容均失败且不留下半成品。换到另一工作目录、保持同一 SHIBAN_ROOT，仍应查到同一素材。

旧库和旧主文件名无需强制改写；实际旧库验收应先使用备份副本。不要对真实库执行临时示例或重置操作。

## 科学内容边界

细胞周期示例验证阶段顺序与编排机制，时间比例不是实际细胞周期测量值。碱基示例只展示配对关系和腺嘌呤所属嘌呤的稠合双环骨架，省略原子标识、取代基与键级；不能当作完整化学结构式。现有正式结构式素材可在你确认科学性后另行复用，本轮不复制真实个人库到源码。

## 工具验收

源码中新增 suggest、compose 和 compose_schema 可发现入口；compose 规格及原始证据大文本走 stdin。由于本轮未安装运行时，当前 GUI 的工具目录不应被当作已更新。待你决定安装时再验证宿主真实调用。
