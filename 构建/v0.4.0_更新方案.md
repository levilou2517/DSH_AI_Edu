## 一、总纲：本次优化什么

| 维度 | 旧（v0.3.0） | 新（v0.4.0） |
|---|---|---|
| 编排模型 | 固定流水线（教案→随堂测→评价→画像） | **原子组合**：技能可独立/串/并/嵌，主 Agent 现场组装 |
| 技能触发 | 有隐含前置（如 quiz 要求先有教案） | **去前置依赖**，缺输入不阻塞、降级并声明 |
| "类型" | 隐含四模块闭环 | **类型 = 默认组合方案**（命名锚点，非封闭枚举），对话微调 |
| 无学生场景 | 无处理 | **微格内省模式**（class-eval 模式B） |
| 教师培养 | 仅存偏好 | **培养主线**：内省→技能点→成长报告 |
| 组织形式 | 黑盒 | **task_plan.json**（仅多轨/分段/跨会话时） |
| 数据治理 | 全量落盘 or 全量入库（二选一） | **分层 L0/L1/L2 + 任务状态驱动**（见 §三） |

**一句话**：技能已原子化，本次**补完契约 + 重写编排语法 + 引入数据分层**。

## 三、核心新设计：数据分层与任务状态（P7/P8）

### 3.1 三层数据

```
L0 原始材料  ── 完整落盘、不精简、独立备份（工作区内）
                课堂记录 / 微格录像转写 / 教师随手笔记 / 同伴观察…
L1 进行中工作 ── 详尽的结构化产物（重）
                current_*.json / task_plan.json / last_microeval.json …
L2 历史记录  ── 轻量"连接"（轻）：指向 L0 的引用 + 关键结论/趋势/索引
                归档动作 = AI 把 L1 详版提炼为 L2 连接，L0 原样保留不丢
```

### 3.2 任务状态机（P8）

```
任务创建 ──status: 进行中──→（完成/归档）──status: 已归档──→ L1 详版 → L2 连接
                                                    （L0 不变）

状态切换由 AI 辅助执行（归档时提炼），人不手工整理。
```

### 3.3 AI 辅助管理职责

- 归档时把 L1 详尽产物**提炼**为 L2 连接（保留引用、结论、趋势，丢弃过程细节）。
- 保证 L0 原始材料**不丢、不改**。
- 报告/查询默认走 L2（轻）；需回溯时经引用回 L0。

**❗待定：** 见 §四-2（物理实现方式）。
