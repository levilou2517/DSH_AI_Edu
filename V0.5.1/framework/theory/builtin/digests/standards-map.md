# 标准 → 判据映射

> 依据：T-BUILTIN-032 / 035 / 034 / 031
> 用途：把国家/考试标准转成产品的可检查项。全部产物（教案、随堂测、课后评价、成长回顾）在交付前都要过一遍本文件。

**页码说明（重要）**：`理论库/标准/` 下只有 T-BUILTIN-031 是 PDF 抽取、带 `<!-- p.N -->` 页序；T-BUILTIN-032 / 034 / 035 由 DOC（`中学教育专业师范生教师职业能力标准（试.docx`、`zhongxue.doc`、`408.doc`）转换而来，**原件无 PDF 页序**。因此：

- T-BUILTIN-031 用 `p.N`；
- T-BUILTIN-032 / 034 / 035 用**条目号**回指（`T-BUILTIN-032 2.3.4`），条目号是原文自带的层级编号，比页码更稳、更可核验；
- T-BUILTIN-034（面试大纲）原文条目无编号，改用**标题名**回指（`T-BUILTIN-034「教学实施」`）。
  以上替代写法不虚构页码，`lesson validate` 遇到这三项请按条目号而不是页码校验。

## 一、四级来源

| 来源 | 管什么 | 编号 | 回指方式 |
|---|---|---|---|
| 师范生教师职业能力标准 | 培养目标与能力维度 | T-BUILTIN-032 | 条目号（1.1.1 … 4.2.2） |
| 中学教师专业标准 | 在职教师专业要求 | T-BUILTIN-031 | 页码 `p.N` + 条目号（1–63） |
| 教师资格·学科知识与教学能力 | 高中生物教师考试要求 | T-BUILTIN-035 | 条目号（一~三、四） |
| 教师资格·面试 | 试讲/答辩的观察维度 | T-BUILTIN-034 | 标题名 |

四者的关系与分工：

- **T-BUILTIN-032 是测评的一级依据。** 它的"教学实践能力"一节（2.1–2.3）覆盖了从专业知识到设计、实施、评价的完整链路，且对每一环都给了**可观察的动作**——这是本系统判据的主要出处。它通篇用"联系"作操作动词：学科与其他学科的**联系**〔T-BUILTIN-032 2.1.4〕、教学内容与学生已有知识经验的**联系**〔T-BUILTIN-032 2.2.3〕、学习内容与生活经验的**联系**〔T-BUILTIN-032 2.3.1〕。判据里凡问"联系"处，都必须能指出**两端的实体**（谁与谁联系）与**凭据**（凭什么说二者有联系），不接受只写"联系生活实际"〔推断〕。
- **T-BUILTIN-031 是同一能力在在职教师阶段的表述**，用于校验判据在真实课堂里同样成立（如"依据课标进行教学的意识和习惯"〔T-BUILTIN-031 p.5〕）。
- **T-BUILTIN-035 把上述能力落到生物学科与考试形态**，提供学科特有的检查点（教材地位、核心概念、三维目标的准确表述）〔T-BUILTIN-035「（三）教学设计」〕。
- **T-BUILTIN-034 是外部观察视角**：它以第三方考官语言描述"好到什么程度"，用于把内部判据翻译成微格/展评时可见的信号〔T-BUILTIN-034「二、测试目标」〕。

## 三、教资面试七维 → 微格评价维度

T-BUILTIN-034 给出的观察维度是：职业认知、心理素质、仪表仪态、言语表达、思维品质、教学设计、教学实施、教学评价（共 8 个标题，其中"思维品质"为面试独有）〔T-BUILTIN-034「三、测试内容与要求」〕。"七维"指任务约定的 7 个主维度；"思维品质"因直接对应学科能力，单列为第 8 项一并处理。

| 维度 | 观察信号 | 本系统能否评价 | 说明 |
|---|---|---|---|
| 职业认知 | 是否说出从教意愿、对教师职业特征的理解、对师德情境的分析 | **部分** | 可从教案的教学主张、争议项处置、`teacher_view` 的措辞判断"是否讲出自己的教育立场"；但"热爱""认同"属态度，文本无法证实，只能标为教师自述〔T-BUILTIN-034「（一）职业认知」〕〔medium〕 |
| 心理素质 | 情绪调节与自控、应变（"能够冷静地处理问题，有应变能力"）〔T-BUILTIN-034「（二）心理素质」〕 | **不能** | 需要现场压力情境；文本与录像都无法可靠判定情绪状态。可做的替代：记录"偶发事件"的处理动作（教案风险项、内省的犹豫点），只评**行为**不评**心理** |
| 仪表仪态 | "仪表整洁，符合教育职业和场景要求"；"举止大方"〔T-BUILTIN-034「（三）仪表仪态」〕 | **不能** | 需真人影像与现场判断，且评价涉及人身，超出 Agent 权限。**明确不评**：系统不得基于照片、着装、身高体态、面部特征给出任何描述或分数 |
| 言语表达 | 语速、清晰度、层次、有无口头禅式填充词 | **部分（仅限转写文本）** | 能从课堂转写看：讲授是否单段过长、是否用封闭化表述（"就是""记住"）、追问后是否回收。**不能**判断"发音标准、声音洪亮、语速适宜"——这些需要音频与听觉判断，转写稿不含这些信息〔T-BUILTIN-034「（四）言语表达」〕 |
| 思维品质 | 逻辑性、全面性、灵活性与应变、创新思路〔T-BUILTIN-034「（五）思维品质」〕 | **部分** | 可从产物结构判断逻辑性（目标—活动—评价是否对齐、反驳条件是否成立）；"应变"部分不能评（同心理素质）〔low〕 |
| 教学设计 | 教材地位、目标与重难点、学生主体性（"教学设计体现学生的主体性"）〔T-BUILTIN-034「（六）教学设计」〕 | **能** | 第二节第 1–10 行即为本维度的可检查化；全部为文本可判定项 |
| 教学实施 | 情境创设、呈现是否准确、提问启发性、板书、环节与节奏〔T-BUILTIN-034「（七）教学实施」〕 | **部分** | 教案阶段只能查"设计是否合理"；"实施"需课堂证据（转写/录像）才能评。无学生证据时按 `evidence-levels.md` 第四节走微格内省 |
| 教学评价 | 过程性评价、能否客观评价自己的教学效果〔T-BUILTIN-034「（八）教学评价」〕 | **能（过程性评价）/ 部分（自我评价）** | 过程性评价对应第二节第 14–16 行；"客观评价自己"需与 `model_view` 对照后看 `divergence`，是**相对**判断，不单独打分 |

**Agent 无法评价的维度（诚实标注）**：`仪表仪态`（完全不能）、`心理素质`（完全不能）。
**仅能部分评价**：`职业认知`、`言语表达`、`思维品质`、`教学实施`、`教学评价（自我评价部分）`。

凡属"不能"的维度，产物中**不得出现任何评分、等级或倾向性描述**；教师若主动询问，回应固定为："该维度需要现场或真人观察，本系统不评价；如需要，可记录观察者的原话供你参考。"〔推断：依据 T-BUILTIN-034「三、测试内容与要求」本身是对考官现场观察的规定，Agent 不占据考官位置〕

另需注意：7 维中与本研究直接相关的**"学生主体性"**判断依赖学生是否真的在活动——纸面教案只能证明"设计了学生活动"，不能证明"学生活动发生了"〔推断〕。这一点与 `evidence-levels.md` 的 B 级规则一致。

## 四、合规检查清单

交付前逐条核对。每条对应一个可机检或可人工核对的判定；任一条不过，**不得提交为 `confirmed`**。

### 4.1 教案（lesson-plan → `les`）

- [ ] **课标锚点**：S1 摘到次位概念原文与编号，并点明落实哪几条、指向哪些素养维度。〔T-BUILTIN-032 2.2.1〕
- [ ] **教材地位双端**：S1 写出承上与启下，各带章节定位；写出编排意图。〔T-BUILTIN-032 2.2.4〕〔T-BUILTIN-035「（三）1」〕
- [ ] **核心概念明确**：核心概念 ≤3 个，且每个有学生基础说明。〔T-BUILTIN-035「（三）1」〕
- [ ] **学情有来源**：每条学情判断标注 A/B/C 证据级；无来源者删除或标"待确认"。〔T-BUILTIN-032 2.2.3〕
- [ ] **目标双锚 + 可观测**：每条目标有课标锚与学情锚，动词可观测，只落一个维度。〔T-BUILTIN-032 2.2.4〕〔T-BUILTIN-035「（三）2」〕
- [ ] **重难点来源分家**：重点追课标/教材，难点追学情，且难点有检验题。〔T-BUILTIN-032 2.2.4〕
- [ ] **方法有理由**：每个环节写"为何用此方法"，并能回答"学生在这环节做什么"。〔T-BUILTIN-032 2.3.2〕〔T-BUILTIN-035「（三）3」〕
- [ ] **联系有两端**：所有"联系"处能指出两端实体与凭据（学科↔学科、内容↔经验、新知↔旧知）。〔T-BUILTIN-032 2.1.4 / 2.2.3 / 2.3.1〕
- [ ] **提问有回收**：S8 提问标认知层次与回收方式，至少 1 个应用/分析层。〔T-BUILTIN-032 2.3.2〕
- [ ] **评价对目标**：目标编号集合 = S9 评价行编号集合。〔T-BUILTIN-032 2.2.4〕
- [ ] **板书结构**：主/副/生成性板书各有分工，核心问题在板书中可见。〔T-BUILTIN-034「教学实施」〕
- [ ] **风险与反思位**：每环节有预期风险 + 应对；S11 预留可观察的反思位。〔T-BUILTIN-035「四、4」〕〔T-BUILTIN-031 p.7〕

## 五、边界

1. **标准是"要求"，不是"量规"。** T-BUILTIN-032 与 T-BUILTIN-031 写的是"应当具备什么"，没有给达标等级与阈值；本文档的"怎么算过"全部是项目内把要求**操作化**的产物〔推断〕，不是标准原文的评分表。若与课程标准或教材内部规定冲突，以课标/教材为准。
2. **用词二级来源注意。** T-BUILTIN-031 的**前 1 页为 PDF 页序 `p.1`，但该 PDF 是合订本**（页首同时出现《教师教育课程标准》《师范生教师职业能力标准》等标题），其后各页是否仍属《中学教师专业标准》正文，转换稿无法自证。本文只引用条目号在原文 1–63 范围内、且与《中学教师专业标准》"维度—领域—基本要求"结构一致的条目（如第 56 条"自我评价教育教学效果，及时调整和改进教育教学工作"〔T-BUILTIN-031 p.7〕）；对来源存疑的页段不得引用。
3. **T-BUILTIN-035 的转换缺陷。** 该文件由旧版 `.doc` 抽取，明确提示"纯 ASCII 段落可能丢失"；序号在转换中散落（如"1．学习需求分析"之后的并列项无编号），"试卷结构"一节表格被破坏。因此本文只引用文字完整、语义自足的条目；凡引用处若需精确分值或结构，须回溯 `408.doc` 原件。
4. **T-BUILTIN-034 的转换缺陷。** 同属旧格式转换，"五、评分标准"标题后出现乱码串（原文表格未被正确抽取）。本文引用面试维度**只取"三、测试内容与要求"与评分标准的文字行**，不引用乱码区域，也不据此推断评分权重。
5. **T-BUILTIN-032 是"师范生"进阶段，不是在职教师全部要求。** 用它作为一级测评依据时，须与 T-BUILTIN-031 并置：前者给"能做出来的动作"，后者给"在职课堂的持续要求"（如"依据课标进行教学的意识和习惯"〔T-BUILTIN-031 p.5〕）。只按 T-BUILTIN-032 判，会漏掉"持续改进"类要求。
6. **"不能评价"的边界不得被产品需求突破。** 仪表仪态、心理素质的排除是权限边界，不是技术暂时不足；不得以"多模态数据支持"为由重新纳入。
7. **冲突处理。** 本框架与教师补充文献（`T-DERIVED-*`）冲突时，以教师补充为准，并在产物 `controversy[]` 记录冲突点与教师选择；教师保有最终解释权。
