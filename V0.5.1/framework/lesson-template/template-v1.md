## 一、课标及教材分析

> 填写提示：本章回答「这节课为什么这样定位」。课标分析**只摘与本课直接相关的条目**，教材分析要落到「本节在概念体系中的位置」，两节合起来为第三节的「重点」提供出处。常见失分：整段复制课标导言、把大段课标原文当分析、教材分析只写目录位置而不写编排意图。

### 1、课标分析

> 填写提示：【必填】按「**模块 → 大概念 → 重要概念 → 次位概念 → 学业要求**」逐级摘录，次位概念写课标原文编号与文字；最后一句必须点明「本课落实哪一条、指向哪几个素养维度」，并与第四节目标呼应。常见失分：只到大概念就停、漏写学业要求指向的素养、把「学业质量水平」与「学业要求」混为一谈。

- **所属模块**：【如：必修课程模块2「遗传与进化」】
- **概念层级**：
  - 大概念：【概念×……】
  - 重要概念：【×.×……】
  - 次位概念：【×.×.×……（课标原文）】
- **学业要求**：【摘录对应条目 + 括注指向的素养维度】
- **学业质量水平定位**：【本课知识性目标锚定水平×，哪一条目标指向水平×】
- **课标对本课的具体指向**：【一句话概括本课应落实的素养目标】

### 2、教材分析

> 填写提示：【必填】按「**本节内容 → 编排意图 → 章节内部地位 → 前后知识联系 → 总体定位**」五层展开；「编排意图」是拉开差距的一层——教材为什么这样安排顺序（如先推测后证据），直接决定了你的教学路径能否成立。常见失分：只写「本节是第×节」而不解释承上启下具体承接什么、为哪节课奠基。

- **本节内容概述**：【教材通过什么情境/栏目展开，包含哪些核心知识，本节聚焦什么问题】
- **编排意图**：【教材的呈现顺序透露了什么方法论，如「先推测后证据」即假说—演绎的完整呈现】
- **章节内部地位**：【承接哪节、为哪节奠基】
- **跨章节/跨模块联系**：【与后续章节、其他模块、初中知识的关联】
- **总体定位**：【一句话概括本节在概念体系中的作用】

## 二、学情分析

> 填写提示：固定三维度：**一般特征（谁在学）→ 学习风格（怎样学）→ 学习起点（已经会什么、卡在哪里）**。每个维度结尾都要落到「因此我将……」，只描述不回应是本章最普遍的失分。学情直接决定「难点」与「支架」，第三节的难点与第七节的认知阶梯都必须能从本章找到出处。

### 1、一般特征分析

> 填写提示：【必填】写认知发展阶段、已有知识基础、思维方式与能力特点三段，最后一句落到教学对策（如「本课不把重心放在获取新事实，而放在综合运用已有工具解决新问题」）。要具体到本班，避免「学生思维活跃、求知欲强」这类套话。

- **认知发展阶段**：【如：形式运算阶段，抽象思维初步发展】
- **已有知识基础**：【前序已学内容，写出具体章节】
- **思维与能力特点**：【比较、归纳、逆向推理、跨学科迁移等】
- **教学对策**：【据此将采用……方式】

### 2、学习风格分析

> 填写提示：【必填】写认知方式（场依存/场独立）、合作倾向、学习偏好，并补上「课堂管理预案」——活跃班如何防止发散跑题、沉闷班如何激活参与。管理预案往往是评委判断「这是真课堂还是纸面教案」的关键。

- **认知方式**：【场依存/场独立，偏好直观或抽象】
- **合作倾向**：【是否乐于小组活动，组内是否易出现「少数人操作、多数人旁观」】
- **学习偏好**：【可视化工具、结构化支架、上台展示等】
- **教学对策**：【提供何种支架、采用何种活动组织方式，如角色分工保证「人人有事做」】
- **课堂管理预案**：【针对本班的预设，如设副板书「问题暂存区」收纳偏题问题】

### 3、学习起点分析

> 填写提示：【必填】三件事：①「已知」逐条写清（能说出具体章节更佳）；②「前科学概念」至少写 2 条，每条附**证据**（前测、作业、教材习题反映的典型错误）与**对策**；③「认知阶梯」用 A→B→C 的箭头写出学生的逐步上升路径，并在关键处标注支架发放时机。常见失分：前概念只列名词不给证据、阶梯写成教学流程而非认知变化的顺序。

- **已知**：【学生已掌握的相关知识，逐条列出】
- **认知难点（前科学概念）**：
  - 前概念①：【学生易混淆、难以理解之处】
    - 证据：【前测问卷/作业/教材习题中反映此点的具体表现】
    - 对策：【如何利用或转化它】
  - 前概念②：【……】
    - 证据：【……】
    - 对策：【……】
- **教学对策**：【如何搭建「××→××→××」的认知阶梯化解难点】
- **认知阶梯**：【A → B → C → D，并标注支架在何处发放】

## 三、教学重难点

> 填写提示：**重点由「课标+教材」决定，难点由「学情」决定**——写作时要能回指第一节与第二节。难点表述必须具体到「学生难在哪一步」，而不是「××比较抽象」。第 3、4 两节（难点成因分析与突破策略）来自参赛作品的增量，建议填写：它们是把难点从「说得出」推到「解得开」的关键。

### 1、教学重点

> 填写提示：【必填】2—3 条，每条一个可讲授、可评价的知识或方法要点，控制在 20 字左右；不要在重点里塞进目标句式。常见失分：重点写成「培养学生科学思维」（那是目标）、重点条数与第八节的核心环节对不上。

1. 【重点1】
2. 【重点2】
3. 【重点3（可选）】

### 2、教学难点

> 填写提示：【必填】1—3 条，写「**做什么** + **难在哪里**」，如「运用演绎推理预测各假说在第一代、第二代的实验结果」；难度须可被第八节的活动与第九节的检测题检验。

1. 【难点1】
2. 【难点2】

### 3、难点成因分析（可选）

> 填写提示：【可选】逐条对应第 2 节的难点编号，写清「成因在于……」：是变量过多、推理链过长，还是学生缺少某种方法论意识（如「把实验结果当作直接读数」）。若只写难度而不写成因，第四节「突破策略」就必然沦为「多讲一遍」。

- 难点（1）的成因在于：【……】
- 难点（2）的成因在于：【……】

### 4、突破策略（可选）

> 填写提示：【可选】与第 3 节一一对应，策略要落到**具体教具、具体表格、具体追问**上（如「预期—结果对照表」「离心管卡纸＋彩色条带贴」），并说明它如何消解该成因；最好还能在第八节找到实施位置。

- 针对难点（1）：【策略】
- 针对难点（2）：【策略】

## 四、教学目标

> 填写提示：【必填】3—4 条，**一条目标对应一个核心素养维度**（生命观念、科学思维、科学探究、社会责任），每条采用「**通过……（学习活动/情境），能……（可观测的行为），形成/发展……（素养）**」句式，行为动词可测（阐明、推导、设计、解释、质疑）。编号固定为 O1—O4，第九节的达成评价与终结性任务必须逐条对应这些编号。常见失分：目标只有知识点没有素养、四条目标其实都在讲同一个维度、行为动词不可测（「了解」「体会」）。

- **O1（生命观念）** 通过【情境/活动】，能【概述/阐明/解释……】，形成【××观】。
- **O2（科学思维）** 通过【模型建构/演绎推理/比较归纳……】，能【推导/归纳/建构……】，发展【模型与建模/演绎与推理……】的科学思维。
- **O3（科学探究）** 通过【小组合作/模拟活动/资料分析……】，能【提出思路/设计记录/交流修正……】，初步掌握【科学探究的基本思路和方法】。
- **O4（社会责任）** 基于【本课知识】，能【对××作出理性分析/向他人科普……】，形成【崇尚科学/关注健康……】的意识。

> 编号 `id` 为 O1—O4，另填三项（render 时以「通过—能—发展—达成标志」呈现）：
> - `on`：通过什么（情境或活动）
> - `can`：能做什么（可观测行为）
> - `develop`：形成/发展什么素养
> - `assessable_sign`：达成标志（第九节据此外显评价）

## 五、教学方法

> 填写提示：【必填】选 2—4 种**与目标的素养维度直接对应**的方法，每种写清「为什么用（依据）+ 怎么用（做法）+ 达成什么（作用）」。方法名词能说出「在本课哪一环节、以什么形式落地」才算数；假说—演绎、建模这类**科学思维方法**要说明它们是本课要培养的对象，而非单纯的教学方法。

1. **【方法一，如：引导发现法】**
   - 依据：【课标/素养要求】
   - 做法：【在本课哪一环节、以什么形式落地】
   - 作用：【突破哪个难点、发展哪种思维】
2. **【方法二，如：小组合作学习法】**
   - 依据：【……】
   - 做法：【分组方式、角色分工、任务类型】
   - 作用：【……】
3. **【方法三，如：演示法 / 情境化教学 / 深度学习】**
   - 依据：【……】
   - 做法：【……】
   - 作用：【……】

## 六、教学准备

> 填写提示：【必填】三节都要写，且**教具清单必须能落实**：数量到组、到人，名称可直接采购或制作。教具与第八节的活动一一对应——活动里用了什么，这里就要列出什么；反过来，这里列了的若第八节没有用到，删掉。常见失分：只写「PPT、黑板、粉笔」，或教具与活动对不上。

### 1、教学环境

> 填写提示：【必填】多媒体设备、网络/离线要求、课件与学案；若用到交互式网页或视频，注明是否需联网与打开方式。

- 【多媒体设备、投影、音响等】
- 【课前准备 PPT、教案、逐字稿、导学案】

### 2、学生准备

> 填写提示：【必填】前测问卷（测哪些前概念，**问卷中不出现本课术语**）、预习任务（课本页码与内容）、学具与分组（每人/每组准备什么）。若某项准备会破坏课堂设计（如提前预告假说种类），要写明「不预告什么」及原因。

- 【前测问卷：检测哪些前科学概念，并注明问卷中回避哪些术语】
- 【预习任务：课本页码与内容】
- 【学具与分组：纸笔、导学案、每组人数与角色分工】

### 3、教师教具准备

> 填写提示：【必填】分「常规 / 演示教具 / 分组教具 / 材料卡 / 学案」几类列，数量写清（每组几张、每套几件）。

- 【常规：PPT、黑板、粉笔等】
- 【演示教具：……（数量、用途、对应哪一环节）】
- 【分组教具：每组……】
- 【学案与材料卡：……】

## 七、教学设计思路

> 填写提示：【必填】用**结构图**呈现「情境主线 + 知识主线 + 素养主线」三线并行，图上标注各环节名称与时长，并与第八节完全一致。不要贴 Mermaid 运行时源码——用 ASCII/框线图或文字版流程，保证离线可打印。结构图下方必须写清四条线，尤其是「核心观念」——它是第十节板书要落在纸上的那句话。

```text
【情境导入】核心问题：________（× min）
        ↓
【环节二：____】活动1 ____ → 活动2 ____（× min）
        ↓
【环节三：____】活动3 ____ → 活动4 ____（× min）
        ↓
【环节四：____】资料/探究 ____（× min）
        ↓
【情境回归与小结】回扣核心问题 → 知识框架 → 素养延伸（× min）
```

- **情境主线**：【真实情境如何贯穿全课，由「现象」出发、以「机制」作答，形成首尾呼应】
- **知识主线**：【××→××→××→××】
- **素养主线**：【本课重点发展的素养及在哪个环节落实】
- **核心观念**：【如：结构决定功能】

## 八、教学过程

> 填写提示：【必填】采用四列表格「**教学环节 | 教师活动 | 学生活动 | 设计意图**」。每个环节在环节名称下标注时长，**所有环节时长之和必须等于〇节写的课时时长**（容差为 0）。教师活动用【情境创设】【任务布置】【追问】【归纳】【过渡】等小标签分层；学生活动要与教师活动逐条对位（教师追问，学生就回答），并写出**可能的错误回答**；设计意图必须点明「培养哪种素养 / 突破哪个难点 / 为什么这样设计」。建议 4—5 个环节；每个环节尽量给出一个可撤除的支架（填在「支架」栏并在活动中标明撤除时机）。

| 教学环节 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|
| **一、【环节名称】**<br>（× min） | 【情境创设】……<br>【追问】……<br>【过渡】…… | 【观察】……<br>【思考并回答】…… | 【创设认知缺口、聚焦核心问题】 |

## 九、教学评价

> 填写提示：【必填】形成性（课堂）+ 终结性（课后任务）结合，三项权重之和建议为 100%（参照：参与 20% + 目标达成 30% + 终结性 50%）。评价**指向核心素养**而非单纯知识点，且与第四节教学目标**逐条一一对应**——这是 validate 的硬检查项。形成性评价包含三部分：①课堂参与评价（A/B/C/D 四级）②目标达成评价（与第四节目标一一对应）③课堂即时检测（随堂 2—3 题，含易错预估）。

### 1、形成性评价

**（1）课堂参与评价（建议 20%）**

> 填写提示：四级 rubric 每级都要写「可观察的行为」（是否上台展示、是否承担角色、是否提出有价值的问题、是否回避提问），而不是「优秀 / 良好 / 一般 / 差」。

| 等级 | 具体表现 |
|---|---|
| A | 能紧跟课堂节奏、主动投入活动，能主动上台展示并逻辑清晰地分享，有效推动小组讨论，能提出有价值的问题。 |
| B | 能跟上课堂节奏，积极配合，认真倾听，能较好完成小组分工，但思维深度与广度有待提升。 |
| C | 多数时间跟随课堂节奏，偶有注意力不集中，小组讨论中较少主动发言，能基本掌握知识点。 |
| D | 对课堂内容不感兴趣，回避提问，小组活动中沉默或从事无关活动，思维脱离课堂。 |

**（2）目标达成评价（建议 30%）**

> 填写提示：【必填】**每一行对应第四节的一条目标**（编号 O1—O4 必须与第四节完全一致，缺一行或多一行都会被 validate 判错）。「目标达成表现」写可观测的外显行为，等级 A—完全达成、B—部分达成、C—基本达成、D—未达成。

| 编号 | 核心素养 | 目标达成表现 | A | B | C | D |
|---|---|---|---|---|---|---|
| O1 | 生命观念 | 【能运用××观，阐明……】 | | | | |
| O2 | 科学思维 | 【能通过……归纳/推导/建构……】 | | | | |
| O3 | 科学探究 | 【能通过……模拟/探究，设计……】 | | | | |
| O4 | 社会责任 | 【能运用知识解释……，认同……】 | | | | |

**（3）课堂即时检测（随堂 2—3 题，建议 5—8 min）**

> 填写提示：【建议】2—3 道题，须能直接检验第四节的目标与第三节的难点；建议覆盖「概念辨析 + 推理判断 + 解释说明」三类。列：题号 / 题目 / 参考答案 / 学生易错预估与应对——**易错预估必须写出具体错误答案（如「答成 1/4」）并给出追问应对**，这是检测题区别于普通习题的地方。题目可用教材练习改编，注明出处；只考本课目标，不出超纲题。

| 题号 | 题目 | 参考答案 | 学生易错预估与应对 |
|---|---|---|---|
| 1 | 【题目……（出处：教材练习第×题）】 | 【参考答案，含关键推理】 | 【典型错误①……；应对：追问……】 |
| 2 | 【题目……】 | 【参考答案】 | 【典型错误……；应对：……】 |
| 3 | 【可选·题目……】 | 【参考答案】 | 【典型错误……；应对：……】 |

### 2、终结性评价

> 填写提示：【必填】设计一个**真实任务/表现性任务**（科普推文、调查报告、模型制作、方案设计），要求分点列出并与核心素养、本课重点对应；评价原则上以「过程是否完整」而非「结论是否正确」为要，只写结论不呈现推理的计为未达成。

- **任务**：【如：以学校「科学社」成员身份，撰写一期科普推文的配文……】
- **要求**：分点列出，每一点能对应到一条目标（在括号里注明 O×）；不以「是否写出正确结论」为唯一依据，而以「推理链是否完整」为主要依据时，要写明评分口径。
- **对应目标**：【O1、O2、O3、O4——须全部出现在第四节的目标编号中】

## 十、板书设计

> 填写提示：【必填】板书呈现**知识结构化**（框架图/概念图）+ **核心观念**。主板书承担「一节课的逻辑主干」，副板书承担「暂存与生成」，生成性板书要写明「学生回答/模型推导的即时呈现位置」。用 ASCII/框线图排版，不用 Mermaid 运行时；如用预期—结果对照表，表格线提前画好、条带贴纸现场贴入，也是板书的一部分。
