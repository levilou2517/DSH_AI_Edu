# 师伴 ShiBan v0.5.1

面向**师范生与新手教师**的循证教学辅助 Agent，作为 DSH 插件分发。

## 支持要求

| 项 | 要求 |
|---|---|
| **DSH** | **0.2.1-rc.5** — 本版基于此版本适配与实测，其他版本未经验证 |
| **Python** | **3.10 – 3.13** — 数据层硬性依赖，不需要 `pip install` |
| **Node** | ≥ 20 |
| 操作系统 | Linux / macOS 已验证；Windows 启动器已补齐但**未经实机验证** |

DSH 0.2.1 把子 Agent 人格从 `tool-subagent.persona` 改为「独立预设 + `agentPreset`」，
师伴 v0.5.1 即按此结构编写。更早的 DSH（如 0.2.0-rc.2）用的是 `persona` 字段，
配置结构不同，无法通用。

装完是一个**空壳**：人格、六项原子技能、数据层就位——教材、素材与课堂证据由你自行导入或在使用中逐步积累。

**安装方式**：在 DSH Web 的**插件**页 → 添加插件 → 填入仓库地址 `https://github.com/levilou2517/shiban-dist` → 安装 → 启用。

全程在界面里完成，不需要命令行。详见下方[从 GitHub 安装](#从-github-安装全程在界面里操作)。

---

## 它不是什么

| | |
|---|---|
| ❌ 一键生成教案的工具 | ✅ **问**出来的教案：师伴以问题引导，你决定，它记录理由 |
| ❌ 自带教材与教案 | ✅ **空包**：教材、论文、教具都由你自己导入，版权归你 |
| ❌ 替你做判断 | ✅ 每次评价并列"模型看到的"与"你说的"，分歧保留 |
| ❌ 黑箱建议 | ✅ 每条理论依据带文献编号与页码，可自行核对 |

**核心理念**：师伴的目标不是帮你完成工作，而是**引导你把工作想清楚**。
判断标准是——产物里"你做的决定"和"它替你做的判断"必须分得开。

## 安装

### 前置

| 项 | 要求 | 说明 |
|---|---|---|
| **DSH** | **0.2.1-rc.5** | 本版即基于此版本适配与实测 |
| Node | ≥ 20 | |
| **Python** | **3.10 – 3.13** | 硬性依赖，不需要 `pip install` |

> **为什么基于 0.2.1-rc.5 适配**：该版本把子 Agent 人格从 `tool-subagent.persona`
> 改为「独立预设 + `agentPreset`」。师伴 v0.5.1 即按此结构编写。
>
> 其他 DSH 版本未经验证——尤其 0.2.0-rc.2 及更早使用 `persona` 字段，
> 与 0.2.1 的配置结构不同。

### 关于 Python

师伴的数据层是 Python 写的，**需要 Python 3.10 或更新版本**：

- **不需要 `pip install`**：只用标准库，零第三方依赖；
- **不随包分发标准库**：`sqlite3`、`hashlib`、`bz2` 等是 C 扩展，只能来自宿主解释器。
  随包副本会覆盖宿主同名模块，造成版本错配，所以不这么做；
- 已在 **3.10 / 3.11 / 3.12 / 3.13** 上验证语法兼容（`tools/check-py310.py` 静态检查）。

版本不对时启动器会明确报错，不会让你看到晦涩的 `SyntaxError`：

```
[error] 需要 Python >= 3.10，当前为 3.9（/usr/bin/python3）。
       升级 Python，或设置 SHIBAN_PY 指向 3.10+ 的解释器。
```

## 从 GitHub 安装（全程在界面里操作）

> 师伴尚未发布到 npm，请用下面的仓库地址安装。

### 方式一：GitHub 仓库地址（推荐）

**① 打开插件页**

DSH Web 左侧侧栏 → **插件**

**② 卸载旧版（如装过）**

在**已安装**列表里找到 `dsh-shiban-preset`（v0.4.x）→ 点卡片 → **卸载** → 确认。

不卸载会让预设列表里出现两个「师伴」，容易选错。

**③ 点「添加插件」**

**④ 粘贴仓库地址**

在包名输入框里填：

```
https://github.com/levilou2517/shiban-dist
```

**⑤ 点「安装」**

Host 会先读出这个地址指向什么，确认显示的是

```
@levilou/dsh-shiban   v0.5.1
```

再继续。

**⑥ 点「立即启用」**

装完会出现**立即启用**按钮，点击即启用组合包并关闭对话框。

直接关掉对话框的话，它会**装好但处于关闭状态**，需要在插件列表里手动打开。

### 方式二：使用已拿到的 zip 包

如果你手上已经有 `shiban-0.5.1.zip`，按下面四步导入。

**① 解压**

解压到一个长期存放的位置，例如：

```
C:\Users\你的名字\Documents\shiban-0.5.1      （Windows）
/Users/你的名字/Documents/shiban-0.5.1           （macOS）
/home/你的名字/shiban-0.5.1                      （Linux）
```

解压后是一个名为 `shiban-0.5.1` 的**文件夹**，里面有 `package.json`、`使用说明.txt` 等。

**③ 复制解压后文件夹的路径**

在文件管理器里进入这个文件夹 → 复制它的**完整路径**。

> **注意**
> - 复制的是**解压出的文件夹**的路径，不是里面的某个文件
> - 必须是**绝对路径**，从盘符或根目录写起
> - **不要带引号**——从文件管理器"复制为路径"常会带上引号，必须去掉
> - 结尾不要留反斜杠
>
> 取路径的稳妥办法：进入该文件夹 → 点文件管理器的地址栏（变成可编辑文本）→ 全选复制。

#### 路径必须以绝对路径开头

DSH 用 Node 的 `path.isAbsolute()` 判断输入是不是路径。
**它不认识 `~`、`.`、`..`**——那只是终端里 shell 的简写，输入框里没有 shell。

一句话规则：

> 路径必须以 `/` 开头（Linux / macOS），或以盘符开头（Windows）。
> **不能用 `~`、`.`、`../` 开头，也不能只写文件夹名。**

**Linux / macOS**

| 填写的 | 能否识别 |
|---|---|
| `/home/levi/Documents/shiban-0.5.1` | ✅ |
| `~/Documents/shiban-0.5.1` | ❌ **`~` 不展开**，被当成包名 |
| `./shiban-0.5.1` | ❌ 相对路径 |
| `shiban-0.5.1` | ❌ 只有文件夹名 |

**Windows**

| 填写的 | 能否识别 |
|---|---|
| `C:\Users\你的名字\Downloads\shiban-0.5.1` | ✅ |
| `C:/Users/你的名字/Downloads/shiban-0.5.1` | ✅ |
| `"C:\Users\...\shiban-0.5.1"` | ❌ 带了引号 |
| `Downloads\shiban-0.5.1` | ❌ 相对路径 |
| `\Users\...\shiban-0.5.1` | ❌ 缺盘符 |

> **Windows 用户特别注意引号**：从文件菜单选"复制为路径"会带上引号，必须去掉。
> 更稳的取法：进文件夹 → 点地址栏（变成可编辑）→ 全选复制。

若仍提示「无法识别这个包名或地址」，在路径前加 `file:` 试一次：

```
file:C:\Users\你的名字\Downloads\shiban-0.5.1
```

**④ 导入并启用**

1. DSH Web 左侧侧栏 → **插件**
2. 点 **添加插件**
3. 在「包名」输入框里粘贴刚才复制的路径
4. 点 **安装**
5. 装完后点 **立即启用**

压缩包里自带 `使用说明.txt`（同样的四步），可以直接转给其他人。

### 拿到 zip 后要做的事（速览）

| 步骤 | 做什么 |
|---|---|
| 1 | 解压到一个长期存放的位置 |
| 2 | 进入解压出的 `shiban-0.5.1` 文件夹，复制它的完整路径 |
| 3 | DSH 插件页 → 添加插件 → 粘贴路径 → 安装 |
| 4 | 点「立即启用」 |

## 装完之后怎么确认

**① 预设列表里有「师伴 v0.5.1」**

新建会话时，预设选择器里应能看到它。

**② 六个技能可用**

选「师伴 v0.5.1」开新会话，问：

> 你现在有哪些技能？

预期列出：`lesson-plan`、`quiz`、`class-eval`、`class-profile`、`teacher-growth`、`html-material`。

**③ 数据根在工作区内**

问：

> 你的数据根在哪个目录？

预期回答是 **`<你当时的工作区>/.shiban`**，不是 `~/.shiban`。

这一点很关键：数据必须落在工作区内，否则会被 DSH 沙箱拒绝写入，日志与产物都会存不下来。

## 第一次使用会怎样

在一个**没用过的工作区**里首次使用时，师伴会：

1. **扫描**工作区内的教材、课标、论文（**只读**，不创建任何东西）
2. **征求同意**：要不要导入？导入哪几类？多大体积？
3. **你同意后**才真正导入

如果它没问就自己导了，说明版本不对，请反馈。

### 它识别哪些材料

| 类别 | 判定依据 |
|---|---|
| `textbook` | 文件名含「必修 / 教科书 / 教材 / 课本」，或目录名含「教材」 |
| `standard` | 文件名含「课程标准 / 考试大纲 / 专业标准」等，或目录名含「标准」 |
| `paper` | 目录名含「文献 / 论文 / 研究」，或文件名含「研究 / 综述」 |
| `lesson` | 文件名含「教案 / 教学设计」 |
| `asset` | `.html` / `.htm` |

**自动跳过**：`.git`、`node_modules`、`.venv`、`dist`、`build`、插件自身、
证据与个人数据（`raw` / `evidence` / `triage` / `logs`）、README 之类说明文件。

**去重**：同一份材料的 PDF 与 MD 只导 PDF，MD 记为同源。

识别规则可在工作区的 `.shiban/bootstrap.json` 里覆盖，不写死任何本机路径。

## 升级

插件页提示：**安装后暂不支持自动更新，升级需先卸载再装新版。**

流程：插件页 → 卸载「师伴 v0.5.1」→ 添加插件（GitHub 地址）→ 安装 → 启用。

数据在 `<工作区>/.shiban/`，**卸载不会删除**。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示「无法访问 GitHub」／「连接 GitHub 超时」 | 网络连不上 GitHub | 改用**方式二**（本地压缩包） |
| 装完预设列表里找不到 | 装了但没启用 | 插件页找到卡片，打开开关 |
| 出现两个「师伴」 | 旧版没卸载 | 卸载 `dsh-shiban-preset` |
| 安装时要求允许构建脚本 | pnpm 拦截依赖脚本 | 点「允许这些脚本并重试」 |
| 会话里说数据根是 `~/.shiban` | 装的是旧版本 | 确认版本为 v0.5.1 后重新安装 |
