================================================================
  师伴 ShiBan v0.5.1  —  导入 DSH 说明
================================================================

这是一个 DSH 插件文件夹。下面是把它导入 DSH 的步骤，
全程在 DSH 网页界面完成，不需要命令行。


----------------------------------------------------------------
准备
----------------------------------------------------------------

· DSH 0.2.1-rc.5 —— 本版就是针对这个版本做的适配。
  其他 DSH 版本未经验证，装了可能无法启用预设。
· 电脑装有 Python 3.10 或更新版本（师伴数据层的硬性依赖，
  但不需要 pip install 任何东西）
· Node 20 或更新版本


----------------------------------------------------------------
四步：解压 → 复制路径 → 导入 → 启用
----------------------------------------------------------------

第 1 步  解压

    把本 zip 解压到你希望长期存放的位置。
    记住解压后那个文件夹的完整路径，第 3 步要用。

    例如解压到：
        C:\Users\你的名字\Documents\shiban-0.5.1
    或
        /Users/你的名字/Documents/shiban-0.5.1
    或
        /home/你的名字/shiban-0.5.1


第 2 步  打开 DSH，进入「插件」页

    DSH Web 界面左侧侧栏 → 插件


第 3 步  点「添加插件」，填入文件夹路径

    在弹出的对话框里，「包名」输入框填入刚才那个文件夹的
    **完整绝对路径**，然后点「安装」。

    注意：
      · 填的是解压出的**文件夹**路径，不是里面的文件，也不是 zip 本身
      · 必须是**绝对路径**，从盘符或根目录写起
      · **不要带引号**（复制路径时常会带上，要去掉）
      · 结尾不要留反斜杠

    取路径的稳妥办法：进入该文件夹 → 点文件管理器的地址栏
    （会变成可编辑的文本）→ 全选复制。

    一句话规则：
        路径必须以 / 开头（Linux/macOS），或以盘符开头（Windows）。
        不能用 ~ 、. 、../ 开头，也不能只写文件夹名。
        因为 ~ 只是终端里的简写，这个输入框里没有终端。

    Linux / macOS 路径格式：
        正确    /home/你的名字/Documents/shiban-0.5.1
        错误    ~/Documents/shiban-0.5.1        ~ 不会展开
        错误    ./shiban-0.5.1                  相对路径
        错误    shiban-0.5.1                    只有文件夹名

    Windows 路径格式：
        正确    C:\Users\你的名字\Downloads\shiban-0.5.1
        正确    C:/Users/你的名字/Downloads/shiban-0.5.1
        错误    "C:\Users\...\shiban-0.5.1"     带引号
        错误    Downloads\shiban-0.5.1            相对路径
        错误    \Users\...\shiban-0.5.1          缺盘符

    若提示「无法识别这个包名或地址」，在路径前加 file: 再试：
        file:C:\Users\你的名字\Downloads\shiban-0.5.1


第 4 步  点「立即启用」

    装完后对话框会出现「立即启用」，点它即完成。


----------------------------------------------------------------
装好后的确认
----------------------------------------------------------------

新建会话时，预设列表里应出现「师伴 v0.5.0」。
如果找不到，回插件页看看它的开关是否打开。


----------------------------------------------------------------
常见问题
----------------------------------------------------------------

Q: 提示「无法识别这个包名或地址：not a package name...」
   路径没被识别成"路径"，被当成 npm 包名去校验了。按顺序排查：
     1. 是不是以 ~ 或 . 开头？改成完整路径（/home/... 或 C:\...）
     2. 有没有被引号包住？去掉引号
     3. 是不是解压出来的那一层文件夹？不是它的上一层，也不是 zip 本身
   仍不行就在路径前加 file: 再试

Q: 提示「不是包」或找不到 package.json
   路径填错了。要填解压出来的**那个文件夹**，而不是它的上一层，
   也不是 zip 文件本身。

Q: 提示需要 Python
   电脑没装 Python 3.10+，或装了但不在系统路径里。
   安装 Python 3.10 或更新版本后重试。

Q: 预设列表里找不到「师伴」
   装了但没启用。回插件页找到卡片，打开开关。

Q: 之前装过旧版师伴
   先在插件页卸载旧版（dsh-shiban-preset），再导入本包。
   否则预设列表会出现两个「师伴」，容易选错。
